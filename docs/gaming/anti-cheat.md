# Anti-Cheat on Linux

Multiplayer games with kernel-level anti-cheat are the biggest challenge.

## Game Compatibility

| Anti-Cheat | Linux Support |
| :--- | :--- |
| **Easy Anti-Cheat** | ✅ Mostly Working |
| **BattlEye** | ✅ Working |
| **VAC** | ✅ Working |
| **GameGuard** | ❌ Not Working |
| **Kernel AC** | ❌ Not Working |

## Games That Work

- **Valorant** → ❌ Not working (kernel-level)
- **Fortnite** → ✅ Via Epic
- **Apex Legends** → ✅
- **Call of Duty** → ⚠️ Mixed
- **PUBG** → ✅
- **Rainbow Six** → ✅

## Solutions

1. Check **[ProtonDB](https://www.protondb.com)**
2. Use Proton-GE for better anti-cheat support
3. Wait for game updates

## Kernel Anti-Cheat

Games requiring kernel-level anti-cheat access cannot run on Linux (or dual-boot Windows). This is a game publisher decision.
