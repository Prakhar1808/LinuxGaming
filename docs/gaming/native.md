# Native Linux Games

Many great games run natively on Linux without any compatibility layer.

## Where to Find

- **Steam**: Filter by "Linux" in store
- ** itch.io**: Native Linux tag
- **GOG**: Linux column in search
- ** Lutris**: Native category

## Top Native Games

- **Dota 2**
- **Counter-Strike 2**
- **Portal**
- **Left 4 Dead 2**
- **Rocket League**
- **Among Us**
- **Valheim**

## Native Always Runs Better

Check if a native version exists before using Proton.

## PortWine

Some "Windows" games actually have Linux binaries bundled. Use [PortWine](https://github.com/SteamGridDB/steam-cloud) to find them.
