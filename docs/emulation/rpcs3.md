# RPCS3 (PlayStation 3)

RPCS3 is the best PS3 emulator, capable of running many PS3 games on Linux.

## Installation

```bash
# Flatpak (Recommended)
flatpak install flathub org.rpcs3.RPCS3
```

## Setup

1. Download and install firmware from PS3 system update
2. Configure in Settings → GPU
3. Set renderer to Vulkan for best performance

## Performance

- Use Vulkan backend
- Enable async shaders
- Set appropriate SPU threads
- Check compatibility list on rpcs3.net
