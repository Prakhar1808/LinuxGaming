# Retro Gaming

Emulate classic consoles on Linux.

## Emulators

| Console | Emulator | Install |
| :--- | :--- | :--- |
| **RetroArch** | All-in-one | `flatpak install flathub com.retroarch.PseudoRetroarch` |
| **PCSX2** | PS2 | `flatpak install flathub org.pcsx2.PCS2` |
| **Dolphin** | GC/Wii | `flatpak install flathub org.dolphin_emulator.dolphin` |
| **rpcs3** | PS3 | `flatpak install flathub org.rpcs3.RPCS3` |

## Performance Tips

- Use **Dolphin** Vulkan backend for better performance
- Enable async shader compilation
- Use upscaling for old games
