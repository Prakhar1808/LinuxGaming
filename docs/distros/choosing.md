# Choosing a Distro

Linux gaming works on almost any distro, but some are better optimized.

## Recommended Distros

| Distro | Best For | Package Manager |
| :--- | :--- | :--- |
| **Nobara** | Gaming-first experience | DNF |
| **Pop!_OS** | NVIDIA support | APT |
| **Ubuntu/Mint** | Community support | APT |
| **Fedora** | Cutting-edge software | DNF |
| **Arch/Endeavour** | Latest packages | Pacman |
| **Debian** | Stability | APT |

## Our Recommendation

**New users**: Start with **Nobara** or **Pop!_OS**.

## Pre-Install Checks

- Check hardware compatibility (WiFi, GPUs, etc.)
- Verify game support on ProtonDB
- Ensure 50GB+ free space
