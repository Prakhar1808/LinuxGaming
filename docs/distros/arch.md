# Arch Linux

For users who want the latest packages and full control.

## Installation

```bash
sudo pacman -S steam
```

## Gaming Packages

```bash
# Essential
sudo pacman -S steam gamemode mangohud

# NVIDIA
sudo pacman -S nvidia nvidia-utils nvidia-settings

# AMD Mesa
sudo pacman -S mesa vulkan-radeon

# Vulkan
sudo pacman -S vulkan-icd-loader
```

## AUR Helpers

Use **yay** or **paru** for AUR packages:

```bash
yay -S proton-ge-bin protonup-qt
```
