# Ubuntu / Debian

Popular, stable distributions with huge community support.

## Installation

```bash
sudo apt update
sudo apt install steam
```

## Gaming Packages

```bash
# Essential
sudo apt install steam gamemode mangohud

# NVIDIA
sudo apt install nvidia-driver-xxx

# AMD Mesa
sudo apt install mesa-vulkan-drivers
```

## Ubuntu-Based

Works the same on **Linux Mint**, **Pop!_OS**, **ZorinOS**, etc.

## PPA for Newer Software

```bash
# Mesa (if needed)
sudo add-apt-repository ppa:kisak/tkg

# Wine
sudo add-apt-repository ppa:wine/wine-builds
```
