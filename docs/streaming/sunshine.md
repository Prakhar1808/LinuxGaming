# Sunshine

Sunshine is a self-hosted GameStream server, replacement for NVIDIA GameStream.

## Installation

```bash
# Ubuntu/Debian
sudo apt install sunshine

# Arch
yay -S sunshine
```

## Setup

1. Run Sunshine
2. Open web UI (https://localhost:47990)
3. Add games
4. Pair with Moonlight

## Requirements

- NVIDIA GPU (for encoding)
- Sunshine on host
- Moonlight on client
