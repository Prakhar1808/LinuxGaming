# Moonlight

Moonlight is a NVIDIA GameStream client for streaming PC games to other devices.

## Installation

```bash
# Flatpak
flatpak install flathub com.moonlight_stream.Moonlight

# Ubuntu/Debian
sudo apt install moonlight-embedded
```

## Setup Server

1. Install **Sunshine** on your gaming PC
2. Enable GameStream in NVIDIA GeForce Experience
3. Connect from Moonlight

## Uses

- Steam Link replacement
- Stream to Linux/Steam Deck
- Low-latency streaming
