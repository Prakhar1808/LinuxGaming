# Lutris

Lutris is a game manager that handles games from various sources including Steam, GOG, and installers.

::: warning
Lutris is no longer actively maintained. Use **Heroic** for Epic/GOG/Amazon games.
:::

## Installation

```bash
# Ubuntu/Debian
sudo apt install lutris

# Fedora
sudo dnf install lutris

# Arch
sudo pacman -S lutris
```

## Usage

1. Add game source (Steam, GOG, etc.)
2. Install runner (Wine, DOSBox, etc.)
3. Configure and launch

## Community Scripts

Lutris has user-submitted install scripts for many games. Search the Lutris website for game-specific configs.
