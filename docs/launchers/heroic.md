# Heroic Games Launcher

Heroic is the best way to play games from **Epic Games Store**, **GOG**, and **Amazon Luna** on Linux.

## Installation

```bash
# Via Flatpak (Recommended)
flatpak install flathub com.heroicgameslauncher.hgl
```

## Setup

1. Sign in to your Epic/GOG/Amazon account
2. Configure Wine/Proton version in Settings
3. Install games!

## Configuring Wine

1. Settings → Wine/ Proton
2. Add new version (Proton-GE recommended)
3. Set as default

## Fixes

- **DXVK**: Enabled by default for better performance
- **Esync/Fsync**: Enable in Wine Settings
- **Windows Version**: Set to Windows 10 if needed
